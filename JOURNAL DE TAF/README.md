# JOURNAL DE TAF : Portfolio de Mornex Bakeyta

Ce dossier documente **de A à Z** la création du portfolio personnel de Mornex Bakeyta : chaque étape, chaque outil, chaque technologie et chaque choix, avec la raison qui l'a motivé.

Il est tenu à jour au fil du travail, séance après séance.

## Organisation du journal

| Fichier | Contenu |
|---|---|
| [01-journal-chronologique.md](01-journal-chronologique.md) | Le récit daté de tout ce qui a été fait, séance par séance. |
| [02-outils-et-technologies.md](02-outils-et-technologies.md) | L'inventaire des outils, langages, bibliothèques et services utilisés : leur nature, leur rôle, leur version. |
| [03-decisions-et-choix.md](03-decisions-et-choix.md) | Chaque décision importante : le contexte, les options envisagées, le choix retenu et sa justification. |
| [04-etapes-du-projet.md](04-etapes-du-projet.md) | La feuille de route : les grandes phases du projet et leur état d'avancement. |
| [05-ressources.md](05-ressources.md) | Les données fournies par Mornex, la documentation consultée, les sources d'inspiration et les liens utiles. |
| [06-profil-de-mornex.md](06-profil-de-mornex.md) | La synthèse de tout ce que l\'on sait sur Mornex (identité, parcours, compétences, projet Orinu, réseaux), avec les sources. |

## Comment lire ce journal

- Pour **comprendre le projet rapidement** : commencer par `04-etapes-du-projet.md`.
- Pour **savoir ce qui s'est passé et quand** : lire `01-journal-chronologique.md`.
- Pour **comprendre pourquoi le projet est construit ainsi** : lire `03-decisions-et-choix.md`.
- Pour **reproduire l'environnement de travail** : lire `02-outils-et-technologies.md`.

## Conventions

- Les dates suivent le format `AAAA-MM-JJ`.
- Chaque décision porte un identifiant (`D-001`, `D-002`…) repris dans le journal chronologique.
- Chaque étape porte un identifiant (`E1`, `E2`…).
